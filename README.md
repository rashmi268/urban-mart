# UrbanMart Data Analysis

## Project Overview
This project presents AI-powered business data analysis using the UrbanMart transaction dataset.

## Tools Used
- ChatGPT
- Microsoft Excel
- GitHub

## Analysis Performed
1. Dataset Exploration
2. Sales and Revenue Analysis
3. Product and Customer Analysis
4. Delivery and Customer Satisfaction Analysis
5. AI-Based Business Intelligence Dashboard

## Project Files
- UrbanMart Analysis Report (PDF)
- UrbanMart Analysis Dashboard (Excel)

## Conclusion
The project analyses sales performance, customer behaviour, product categories, delivery time, and customer satisfaction to provide useful business insights.
